# CloudTasks начальный проект

Это готовый проверочный сервер занятия №2. Создание собственного сервера предусмотрено занятием №4. Запускать команды из корня проекта.

```bash
python -m pip install -r requirements-lock.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

В другом терминале: `curl http://127.0.0.1:8000/health`. Ожидается `{"status":"ok"}`. В Codespaces открыть порт 8000 через панель Ports; проверить `/`, `/health`, `/docs`. URL Codespaces не является постоянным production-развёртыванием.

Преподаватель: опубликовать этот каталог как шаблонный репозиторий, выполнить облачную приёмку из спецификации. Файл compose.lab.yml предназначен только для пробы PostgreSQL; переменная LAB_DB_PASSWORD должна быть задана до запуска. Не хранить пароль в репозитории.
